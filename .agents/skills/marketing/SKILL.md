# Marketing Agent Skill

This skill guides the agent in crafting high-converting marketing copy, planning strategic campaigns, and using established marketing frameworks.

## Quick Start

To write copy for a target audience using a framework (e.g., PAS - Problem, Agitate, Solve):

```markdown
### Target: [Audience] | Goal: [Objective] | Hook: [Hook]

1. **Problem**: Identify the main pain point.
2. **Agitate**: Emphasize the consequences of not solving the problem.
3. **Solve**: Present the product/solution as the ultimate cure.
4. **CTA**: Clear call-to-action.
```

## Workflows

### 1. Copywriting & Frameworks
When asked to write copy (ads, emails, landing pages), select and apply a copywriting framework:
- **AIDA**: Attention (hook), Interest (build connection), Desire (benefits/social proof), Action (CTA). *Best for general ads and landing pages.*
- **PAS**: Problem (pain point), Agitate (emotional amplification), Solve (solution/CTA). *Best for email sequences and cold outreach.*
- **BAB**: Before (current state), After (future state), Bridge (how the product takes them there). *Best for case studies and social posts.*

### 2. Social Media Campaign Strategy
When designing a social media plan or post schedule:
- **Define Theme & Tone**: Match the brand's voice guidelines.
- **Mix Content Types**: 50% Educational/Value, 30% Engagement/Discussion, 20% Promotional/Sales.
- **Hook-Body-CTA Structure**: Keep paragraphs short (<3 lines) and end with a prompt or link.

### 3. SEO Content Outline
When planning blog posts or articles:
- **Keyword Integration**: Match primary keywords to H1 and secondary keywords to H2/H3 headers.
- **Search Intent Alignment**: Classify intent (Informational, Transactional, Navigational) and align tone.
- **Outline Structure**: Hook -> Key Concepts (with actionable takeaways) -> Conclusion -> CTA.
